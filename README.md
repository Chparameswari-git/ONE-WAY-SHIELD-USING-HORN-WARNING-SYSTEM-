# ONE-WAY-SHIELD-USING-HORN-WARNING-SYSTEM-
Python-based road safety project developed during the APSSDC Python Programming Internship to detect wrong-way vehicle movement and provide a horn warning alert using computer vision.

📌 About the Project
One Way Shield Using Horn Warning System is a Python-based road safety project developed during my Python Programming Internship through APSSDC (Andhra Pradesh State Skill Development Corporation).
The project aims to identify vehicles moving in the wrong direction on a one-way road and provide a warning through a horn/alarm system to alert the driver and improve road safety.

🎯 Objective
Detect vehicles traveling in the wrong direction.
Identify violations on one-way roads.
Provide an immediate warning to the driver.
Reduce the risk of accidents caused by wrong-way driving.
Demonstrate the use of Python and computer vision for road-safety applications.

🛠️ Technologies Used
Python
OpenCV
NumPy
Matplotlib
Computer Vision
Video Processing

⚙️ Working
A traffic video is provided as input.
The video is processed using OpenCV.
Vehicles are detected and their movement is monitored.
The direction of vehicle movement is analyzed.
If a vehicle moves in the wrong direction, the system identifies it as a violation.
A horn/warning alert is triggered to warn about the wrong-way movement.
